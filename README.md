# Rose Damt Updates

Public update channel for Rose Damt Android applications.

This repository contains only public release metadata. Application source code remains in private repositories.

Applications:
- Admin — `com.rosedamt.admin`
- Client — `com.rosedamt.client`
- Delivery — `com.rosedamt.delivery`

APK files are published as GitHub Release assets. Clients should read the matching JSON metadata file before offering an update and verify the APK SHA-256 before installation.
